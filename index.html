Pasang aplikasi

  1. Host aplikasi ini di alamat HTTPS.
  2. Buka alamatnya menggunakan Chrome Android.
  3. Tekan menu ⋮ lalu pilih Install app atau Add to Home screen.
  4. Konfirmasi instalasi. Ikon WA Web akan muncul di layar utama.

Aplikasi ini hanya pintasan ke WhatsApp Web. Tidak meminta password, OTP, atau menyimpan pesan.
